## Umfang und Grenzen / Scope and limitations

Die Prüfung umfasste alle 23 gelieferten Dateien: Quellen, HTML, JSON-Tastaturlayout, Tests, Texte, Prüfsummen, Lizenzhinweise sowie lesbare Zeichenfolgen und Blockstruktur der UF2. Trefferbegriffe wie Passwort, SET, Tastencodes und Beispieldaten sind für dieses Projekt erwartbar. Die Firmware ist kein ausgelesenes Geräte-Backup; ihr UF2-Adressbereich enthält den vorgesehenen Passwortsektor nicht. Das beweist nicht automatisch die Abwesenheit jeder denkbaren eingebetteten Information.

All 23 input files were covered: sources, HTML, JSON keyboard layout, tests, prose, checksums, notices, and UF2 readable strings/block structure. Password terminology, SET commands and artificial keycodes are expected. The supplied UF2 does not include the designated password storage sector; this does not prove the absence of every possible embedded datum.

Der historische Prüfbericht vom 10.11.2026 bleibt unverändert als Herkunftsnachweis. Die dort erwähnte vollständige BIN/ELF/Disassembly-Prüfung wurde hier nicht erneut ausgeführt, weil die passenden Build-Artefakte fehlen. Keine neue Aussage über physische USB-Funktion oder Sicherheit aller möglichen Angriffspfade.

The original report dated 2026-11-10 is retained as historical evidence. Full matching BIN/ELF/disassembly verification was not repeated because those build artifacts are absent. No new claim about physical USB behavior or resistance to every attack is made.
