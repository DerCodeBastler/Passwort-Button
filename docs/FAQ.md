# Häufige Fragen / FAQ

| Frage | Antwort |
| --- | --- |
| Nur für KeePass? | Nein. Der Button tippt in das aktuell fokussierte Feld. |
| Warum heißt das USB-Gerät noch KeePass-Taster? | Der Name ist Teil der unveränderten Firmware. Eine interne Umbenennung erfordert Neubau und erneute Prüfung. |
| Kein Laufwerk nach dem Flashen? | Normal: Im Betrieb meldet sich das Gerät als Tastatur und serieller Anschluss. |
| Keine Verbindung? | USB-Datenkabel, Pico-2-Firmware und Chrome/Edge prüfen. Andere Programme am seriellen Anschluss schließen. |
| „Noch gesperrt“? | Nach Verbindung BOOTSEL etwa zwei Sekunden halten, loslassen und innerhalb 60 Sekunden speichern. |
| Falsche Zeichen? | Windows-Tastaturlayout Deutsch (Deutschland) wählen. |
| Zeichen fehlen? | Verzögerung erhöhen, etwa auf 5 oder 10 ms. |
| Ist dies ein Passkey oder FIDO2-Schlüssel? | Nein, es gibt ein gespeichertes Passwort als Tastatureingabe aus. |
| Entfernt ein Update mein Passwort? | Nicht zuverlässig. Der Konfigurationssektor wird von dieser UF2 nicht beschrieben. |
| Warum keine komplette interne Umbenennung? | Erhalt der funktionierenden Firmware hat Vorrang. |

English setup, equivalent troubleshooting and UI translations: [SETUP.en.md](SETUP.en.md).
